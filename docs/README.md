# ProtoFlow documentation

ProtoFlow is a desktop app for designing circuit boards: schematic, parts, PCB layout, checks and manufacturing files, with AI built in. These pages cover the app as released. If something here doesn't match what you see, check that ProtoFlow is up to date.

New here? Read [Getting started](getting-started.md) first.
